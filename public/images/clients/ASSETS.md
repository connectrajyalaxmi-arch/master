# Partner and client logo marks

These local files are monochrome client marks used in the Partners & Clients section. SVG marks are from [Simple Icons](https://github.com/simple-icons/simple-icons); raster marks were downloaded from each organization's website favicon using Google's favicon endpoint.

Available marks: ABB, Adani, AMD, Amazon, Apple, Barclays, HSBC, Informatica, ITC, JSW, JPMorgan Chase, Maldives Airports, Microsoft, Micron Electricals, Philips, Qualcomm, Shilpa Biologicals, Shree Cement, STT Global Data Centres, and Vertiv.

Honeywell, Regenesis Industries, TGV Group, and TEMBO remain text wordmarks because no matching logo file was available in the workspace or from the configured favicon sources.
